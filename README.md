# 📊 Data Analysis Dashboard

An interactive Streamlit application for data exploration, cleaning, visualization, and analysis.

## ✨ Features

- Upload CSV files
- Data preview
- Dataset information
- Missing value analysis
- Data cleaning
- Summary statistics
- Interactive charts
- Correlation heatmap
- Download charts

## 🛠️ Built With

- Streamlit
- Pandas
- NumPy
- Plotly
- Matplotlib

## 🚀 Run Locally

```bash
pip install -r requirements.txt
streamlit run app.py
```
