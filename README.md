# 📊 Data Analysis Dashboard

A professional Data Analysis Dashboard built using **Python** and **Streamlit**.

---

## Features

- 📂 Upload CSV & Excel
- 📊 Dataset Overview
- 🧹 Data Cleaning
- 🔍 Exploratory Data Analysis
- 📈 Interactive Plotly Charts
- 📥 Export Cleaned Dataset
- 📊 Correlation Heatmap
- 📋 Dataset Profile

---

## Tech Stack

- Python
- Streamlit
- Pandas
- NumPy
- Plotly
- Matplotlib
- Seaborn
- OpenPyXL

---

## Installation

```bash
git clone https://github.com/Mdsifatmahmud/data-analysis-dashboard.git

cd data-analysis-dashboard

pip install -r requirements.txt

streamlit run app.py
```
